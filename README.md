# Portafolio — Kevin Almanza

Portafolio con tres trabajos universitarios:

1. **[Prototipos de Interfaces (Header)](projects/interfaces-header/index.html)** — 19 variantes de encabezado web en HTML/CSS/JS. *Diseño de Interfaces Software.*
2. **[EcoLogistics — Arquitectura de Envíos](projects/ecologistics/index.html)** — Diagramas de clases y secuencia con patrones Strategy, Observer y Factory. *Arquitecturas de Software.*
3. **[Modelos de Adquisición de Software y Hardware](projects/estudio-caso/index.html)** — Estudio de caso, debate y simulación de RFP. *Electiva II.*

## Ver en vivo

Publicado con GitHub Pages: activa Pages en **Settings → Pages → Deploy from branch → main / (root)** y el sitio quedará disponible en `https://<usuario>.github.io/<repositorio>/`.
